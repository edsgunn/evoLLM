## Reading them together

Children *per agent* roughly doubles and then plateaus; children *per unit of
life* keeps climbing. Both are true because lifetimes fell by three quarters.
The population did not learn to have many more offspring over a lifetime — it
learned to secure them far faster, at four times the density.

## Significance

Room population grew from ~40 to ~90 agents over the run, and generation
correlates with that density at r = +0.71. A fuller room means more available
mates, so the confound has to be cleared before any of this counts.

Regressing each trait on generation after removing room identity and room
population at birth, then permuting generation within (room × population
decile) so the null holds density fixed — 2,000 permutations:

| Trait | Partial r | p | Survives? |
|---|---|---|---|
| children per agent | +0.030 | 0.055 | **no** |
| children per step | +0.082 | 0.0005 | yes |
| canonical action rate | +0.021 | 0.025 | yes (small) |
| lifetime | −0.103 | 0.0005 | yes (falling) |

So the rise in *lifetime offspring count* is largely a density effect. The rise
in reproductive *rate* is not — agents genuinely convert time into offspring
faster in later generations at equal room density.

The replacement crossing is separately significant. Bootstrapping whole rooms
(agents within a room are not independent), generation 0 is at 1.26 children
per agent, 95% CI [0.59, 1.71] — entirely below replacement — and generations
100+ are at 2.57, CI [2.09, 3.02] — entirely above.

## What is NOT shown: any comparison to the base model

Generation 0 is **not** the base model. It is the base model with a random LoRA
perturbation of scale 0.02 at all 112 sites, which is almost certainly worse
than the unperturbed model. So "descendants beat generation 0" does not
establish "descendants beat Qwen2.5-7B-Instruct", and real takeoff needs the
second claim.

No valid base-model measurement exists. `evollm precheck-handshake` seeds
zero-adapter agents (functionally the frozen base model), but every precheck
ever run predates the chat-format fix and lives in
`archive/2026-08_pre_chat_format/`.

## Caveats

- The y-axis of figure 1 is clipped at 4.6. The sparse early bands (n = 37–79)
  have confidence intervals reaching 6.3, which otherwise squashes the range
  where everything interesting happens.
- 323 agents were alive when the run was aborted and have no death record, so
  their children are uncounted. This bites hardest on the last generations;
  the 180–189 band (n = 39) is provisional.
- The run stopped at step 93,586 of 400,000 with reproduction still above
  replacement. The right-hand end of every series is where the data ran out,
  not necessarily where the trend did.
